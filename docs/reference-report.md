## 2. 공통점 (대부분이 공유하는 패턴)

1. **상단 고정(sticky) 가로 헤더** — 좌측 로고 + 우측 글로벌 내비 + (검색/언어), 모바일은 햄버거로 접히는 반응형이 사실상 표준.
2. **수직 스크롤 단일 랜딩 구조** — `히어로 → 콘텐츠 카드 그리드 → 멀티미디어/성과 → 뉴스 → CTA/구독 → 푸터` 순서가 거의 모든 카테고리에서 반복.
3. **대형 히어로 + 짧은 카피** — 고해상도 이미지/영상을 전면에 두고 텍스트는 최소화해 "무엇을 하는 곳인지"를 1초 안에 전달.
4. **카드형 그리드** — 연구분야·프로젝트·뉴스를 동일 규격 타일로 분류해 스캔성과 확장성 확보.
5. **푸터 = 사이트맵 + 소셜 링크** — 헤더 구조를 반복하고 SNS(YouTube/Instagram 등)를 모아 커뮤니티 유입 동선 제공.
6. **명확한 CTA 반복 배치** — 기업은 Careers, 학생팀은 가입/후원/구독, 연구실은 Contact를 눈에 띄게 노출.
7. **성과의 수치화** — 발사 횟수·도달 고도·인용수 같은 큰 숫자로 규모감과 신뢰도를 즉시 전달.
8. **News/Updates 섹션을 홈 가까이** — "지금도 활동 중"이라는 최신성·생존 신호.
